# 스팀 가격으로 보는 플레이 시간 범위

논문 「스팀 유료 게임의 가격과 평균 플레이 시간의 관계」(문영훈, 2026)의 결과를 쓰는 앱입니다.
스팀 유료 게임을 살지 고민하는 사람이 가격을 입력하면, 논문의 가격대별 플레이 시간 중앙값과 25%~75% 범위를 보여 주고 "가격은 경향일 뿐 개별 게임을 예측하지 못한다"는 한계도 알려 줍니다.

## 실행 방법
`index.html`을 더블클릭해 브라우저에서 엽니다. 설치, 로그인, 서버가 필요 없습니다.

## 앱에 들어간 데이터
| 데이터 | 출처 | 개인정보 |
|---|---|---|
| 가격대 4개의 게임 수, 25%·50%·75% 플레이 시간 | 논문 5.2절 표와 부록 (D). 허깅페이스에 공개된 스팀 게임 데이터를 집계한 값 | 없음 (게임 단위 집계 통계) |
| 예시 가격 버튼 4.99 / 9.99 / 19.99 / 39.99 | 이 앱을 시험하려고 직접 정한 예시 값 | 없음 |

- 이용자 개인의 플레이 기록, 이름, 연락처는 앱에 없습니다. 논문 원자료(약 12만 건)도 앱에 넣지 않았습니다.
- 사용자가 입력한 가격은 화면에서 계산하는 데만 쓰이고 저장하거나 외부로 보내지 않습니다. (쿠키, 브라우저 저장소, 네트워크 요청 모두 쓰지 않음)

## 환경 변수 / 비밀값
**필요한 환경 변수가 없습니다.** 이 앱은 AI 서비스나 외부 API를 부르지 않아 키, 토큰, 비밀번호가 소스와 화면에 없습니다.
나중에 AI 서비스를 붙인다면 키는 소스에 쓰지 않고 `STEAM_APP_AI_KEY` 같은 환경 변수로만 읽고, 이 README에 변수 이름만 적습니다.

## 한계
- 숫자는 집단 경향입니다. 같은 가격대에서도 게임마다 플레이 시간이 크게 다릅니다.
- 상관이지 인과가 아닙니다. 30달러 초과 구간은 게임이 185개뿐이라 해석에 주의가 필요합니다.
