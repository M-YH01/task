# 과제10 사전 기준 문서: 스팀 게임의 가격과 평균 플레이 시간

작성일: 2026-10-21 (데이터를 열어 보기 전에 작성)

이 문서의 기준은 데이터를 열기 전에 정했다. 분석을 시작한 뒤 기준을 바꾸면 맨 아래 "변경 이력"에 날짜와 이유를 남긴다. 결과를 맞추려고 고치지 않는다.

## 1. 관심 분야
컴퓨터 게임과 인터넷 방송 시청. 이 중 공개 데이터로 오늘 안에 검증할 수 있는 컴퓨터 게임 쪽에서 주제를 골랐다.

## 2. 검토한 후보 주제 (질문 10개에서 7개로 압축)
AI와 함께 이 분야에서 확인해 볼 질문 열 개를 뽑았다. 직접 데이터를 모으기 어려운 세 개(시험 기간의 변화, 구매 기록 영향, 성적 변동)는 먼저 뺐고, 남은 7개를 "무엇이 무엇에 영향을 준다" 문장으로 바꿨다. 이후 작성자의 사정(오늘 안에 끝내기, 직접 수집하지 않기)에 맞춰 공개 데이터가 이미 있는 주제를 추가로 찾았다.

| 후보 | 가설 문장 |
|---|---|
| 방송 시청 → 플레이 시간 | 방송 시청 시간이 길수록 같은 날 직접 플레이 시간은 짧다 |
| 연패 → 재시작 지연 | 연패 뒤에는 다음 판 시작이 늦어진다 |
| 늦은 시청 → 수면 | 자정 이후 방송을 본 날은 수면 시간이 짧다 |
| 발표 → 시청자 수 | 패치나 신작 발표 뒤 그 게임 방송 시청자 수가 늘어난다 |
| 제목 길이 → 시청자 수 | 방송 제목이 길수록 시청자 수가 적다 |
| 시청자 수 → 채팅 속도 | 시청자 수가 많을수록 채팅 속도가 빠르다 |
| 시작 시간대 → 시청 시간 | 밤에 시작한 방송은 낮에 시작한 방송보다 시청 시간이 길다 |
| 가격 → 평균 플레이 시간 | 스팀 유료 게임은 가격이 높을수록 평균 플레이 시간이 길다 (최종 선택) |

## 3. 접은 주제 세 개와 이유
1. **연패 → 재시작 지연.** 실제로 데이터 수집 도구까지 만들었으나 접었다. 작성자의 게임 플레이 횟수가 적어 "연패 후"와 "승리 후" 비교에 필요한 표본이 모이지 않는다고 판단했다. 연패의 기준, 비교 대상, 긴 공백 처리 문제를 지적받아 다듬었으나 표본 문제는 해결되지 않았다.
2. **제목 길이 → 시청자 수.** 가설과 수집 도구까지 만들었으나 접었다. 확인한 범위에서 치지직 공식 API는 지금 방송 중인 목록만 돌려주고 과거 기록 조회는 문서에서 찾지 못했다. 그래서 앱 등록과 며칠간의 직접 수집이 필요한데, 작성자가 오늘 안에 끝내고 직접 수집하지 않기를 원했다.
3. **내 시청 일지(시작 시간대 → 시청 시간, 늦은 시청 → 수면).** 작성자가 직접 기록해야 하고 한 명의 자료라 일반화가 약하다. 수면 시간은 기억에 의존해 오차가 크다. 며칠의 기록이 필요해 오늘 안에 끝낼 수 없다.

기타 후보(방송 시청 → 플레이 시간, 발표 → 시청자 수, 시청자 수 → 채팅 속도)는 인과 방향이 양쪽이라 영향을 주장하기 어렵고, 공개 통계 확보 방법이 불확실하며, 채팅 수 측정이 복잡해서 순위에서 밀렸다.

## 4. 최종 가설
> **스팀의 유료 게임은 가격이 높을수록 평균 플레이 시간이 길다.**

- **무엇이 무엇에 영향을 주는가:** 게임의 가격(원인)이 출시 이후 평균 플레이 시간(결과)에 영향을 준다.
- **한계:** 상관 분석이라 인과를 증명하지는 못한다. 가격이 높은 게임은 원래 분량이 많거나 온라인 요소가 있어 플레이 시간이 길 수 있다.

## 5. 측정 방법
- **가격:** 데이터의 `price` 열(미국 달러로 가정, 설명서로 확인). 할인 전 정가인지도 설명서로 확인한다.
- **평균 플레이 시간:** `average_playtime_forever` 열. 출시 이후 전체 평균이며 단위는 분으로 가정하고 시간으로 환산한다(설명서로 확인).
- **분석 방법:** 가격과 평균 플레이 시간의 스피어만 순위 상관계수와 유의확률. 효과 크기(상관계수)를 함께 해석한다(관례: |rho| 0.1 약함, 0.3 중간, 0.5 강함).
- **보조 분석:** (1) 가격대 구간별(0~5, 5~15, 15~30, 30 초과 달러) 평균 플레이 시간의 중앙값, (2) 게임 수가 많은 상위 6개 장르별 상관.

## 6. 틀렸다면 어떤 결과가 나오는가
다음 중 하나면 가설을 기각한다.
- 스피어만 상관계수가 0 이하다. (비싼 게임이 같거나 덜 플레이된다)
- 상관계수가 양수여도 유의확률이 0.05 이상이다. (우연으로 설명된다)

기각되어도 논문으로 완성한다. 데이터가 크면 유의확률이 거의 항상 작게 나오므로 효과 크기를 우선해서 해석한다.

## 7. 데이터와 범위
- **데이터:** 허깅페이스의 Steam Games Dataset (FronkonGames/steam-games-dataset, MIT 라이선스, 약 12만 4천 개 게임). 주소: https://huggingface.co/datasets/FronkonGames/steam-games-dataset
- **내려받은 날짜:** 2026-10-21 / **파일 이름:** train-00000-of-00001.parquet / **행 수:** 124,146 (내려받은 뒤 채움, 기준은 바꾸지 않음)
- **분석 대상 조건:**
  - 가격이 0보다 큰 유료 게임만 쓴다. 무료 게임은 가격 차이가 없어 가설과 맞지 않는다.
  - 긍정+부정 리뷰가 100개 이상인 게임만 쓴다. 리뷰가 적은 게임은 평균 플레이 시간이 불안정하다. 100이라는 값은 임의로 정했다.
  - 평균 플레이 시간이 0보다 큰 게임만 쓴다. 0은 집계되지 않은 값일 수 있다.
- **분석 도구:** `analyze.py`. 위 기준을 코드 맨 위 상수로 고정해 두었다.

## 8. AI와 가설을 다듬은 과정
1. AI에게 분야를 알려 주고 질문 열 개를 받았다. 직접 모을 수 있는 7개를 남기고, 각각을 가설 문장으로 바꾸고 측정 방법과 반대 결과를 적었다.
2. 처음 고른 가설(연패 후 재시작 지연)은 AI가 세 가지 약점을 지적했다. 연패의 기준이 없고, 무엇과 비교해 늦다는지 모르고, 긴 공백이 평균을 망가뜨린다는 점이다. 이에 맞춰 비교군과 제외 기준을 고쳤다.
3. 데이터 방법을 확인하는 과정에서 전적 사이트는 날짜만 나와 분 단위 계산이 불가능함을 알게 됐고, 공식 API(Match-V5)로 시각 정보를 얻는 방법으로 바꿨다. 그러나 작성자의 게임 횟수가 적어 표본이 부족하다고 판단해 주제를 바꿨다.
4. 방송 제목 길이 가설로 바꾸고 치지직 공식 문서를 확인했다. 목록이 시청자 수 순으로 상위만 나오고, 과거 조회는 확인하지 못했다. 직접 수집과 앱 등록이 필요해서 오늘 안에 끝낼 수 없다고 판단했다.
5. 공개 데이터가 이미 있는 주제를 AI가 찾았다. 스팀 게임 데이터를 문서로 확인하고(가격, 평균 플레이 시간, 리뷰, 장르 열 존재), 가격이 평균 플레이 시간에 주는 영향으로 가설을 만들었다. 포함 조건과 기각 조건은 데이터를 열기 전에 정했다.

## 9. 이 가설을 최종으로 고른 이유
- **측정 가능:** 가격과 평균 플레이 시간이 데이터에 열로 이미 들어 있다.
- **오늘 안에 가능:** 직접 수집이 없고 내려받아 스크립트를 한 번 실행하면 된다.
- **반대 결과도 의미 있음:** 비싼 게임이 오히려 덜 플레이된다는 결과도 가격이 만족도와 별개라는 정보를 준다.
- **작성자의 관심과 연결:** 컴퓨터 게임 분야다.
