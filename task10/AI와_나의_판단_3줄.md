# AI와 나의 판단 3줄

1. **AI가 한 일:** 관심 분야에서 질문 후보와 가설 문장을 만들고, 가설의 약점(기준 없음, 비교 대상 없음)을 지적하고, 공식 API 문서와 공개 데이터 문서를 확인하고, 분석 스크립트를 작성했다. 분석 결과의 숫자는 내 컴퓨터에서 스크립트를 실행해 얻었다.
2. **내가 판단한 일:** 게임 횟수가 적어 연패 주제를 접었고, 오늘 안에 끝낼 수 없고 직접 수집이 필요한 방송 제목 주제를 접었으며, 공개 데이터가 이미 있는 스팀 가격 주제로 정했다. 분석 기준(리뷰 100개 이상, 지지 조건)은 데이터를 열기 전에 확정했고, 결과를 보고 바꾸지 않았다.
3. **결과를 받아들이는 방식:** 가설이 지지되었지만 상관일 뿐 인과는 아니라고 보았다. 리뷰 수 기준에 따라 상관이 0.267~0.444로 달라진다는 사후 탐색 결과도 숨기지 않고 실었고, 이를 보고 만든 사후 가설은 같은 데이터에서 나온 것이라 확증이 아니라고 적었다. 단위·기준일을 확인하지 못한 점도 한계로 적었다.
