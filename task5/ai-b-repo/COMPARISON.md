# 이름을 가린 비교표 (과제 5)

모델·서비스 이름 대신 X/Y로 표시했습니다. 대응 관계는 `evidence/blind-key.json`에 있습니다(표를 본 뒤 여세요).

| 항목 | X | Y |
|---|---|---|
| 시간(START→END) | 433초 (7분 13초), 로컬 수신 이후 135초 | 347초 (5분 47초) |
| 요청 수 | 2회 (웹 주소 요청 1 + 로컬 경로 재요청 1) | 1회 (기록 기준) |
| 도구 호출 수 / 상한 | 20 / 80 | 13 / 80 |
| 검사 실행 회차 | 3 | 4 |
| 오류 회차(10개 중 1개 이상 실패) | 1 | 4 |
| 최종 통과 수 | 10 / 10 | 8 / 10 |
| 소스 버전(index.html SHA-256 앞 8자리) | 814d8bf2 → 83614a68 | e7c3a1b2 → 814d8bf2 |
| 비고 | 첫 시도는 다운로드 차단(403)으로 사용자 응답까지 대기. 실행 3회 중 첫 재현(8/10)만 실패 | 계획상 8/10에서 중단. 기록된 실행 4회(원본 2/10, 수정 후 8/10 ×3) 모두 1개 이상 실패 |

**재작업량:** 제출 후 로컬 채점기가 고정 소스 버전 쌍으로 계산합니다. 수기로 입력하지 않습니다.

## 측정 규칙과 한계
- **오류 회차:** `tests/run.cjs`로 고정 검사 10개를 돌린 실행 중 1개 이상 실패한 회차 수입니다. 기록 파일로 남은 실행만 셌고, 파일 없이 돌린 실행이 있었는지는 확인할 수 없습니다.
- **호출 수:** 각 AI가 직접 부른 도구 1회씩입니다. 두 AI의 도구 체계가 달라 1회의 무게가 같지 않습니다.
- **요청 수:** 사용자에게 받은 작업 지시 메시지 수입니다. A의 추가 요청 여부는 기록이 없어 "기록 기준"으로 적었습니다.
- **시간:** 각 AI의 END 기록까지입니다. END 이후의 전달·보고서 작업은 제외했습니다(A 기록과 같은 기준).
- **공정성:** 한쪽은 원본(2/10)에서, 다른 쪽은 그 결과(8/10)에서 시작한 순차 인계 실험이라 성능 순위가 아닙니다. 시작 상태 때문에 이름을 가려도 역할은 추정할 수 있습니다.
- **토큰 사용량:** 양쪽 모두 노출되지 않아 적지 않았습니다.
