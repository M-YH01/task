# AI A와 B 공통 최초 요청 (동일 파일 전달)

과제 3 짤·카드 스튜디오에서 JSON 복원의 입력 검증과 실패 시 기존 작업 보존을 구현하세요. PROTOCOL.md 및 tests/cases.json의 검사 10개를 바꾸지 말고 같은 검사로 전후 상태를 기록하세요. 시간 상한은 AI별 60분, 도구 호출 상한은 AI별 80회입니다. START/END, 실제 호출 수, 통과 검사, 남은 오류, 소스 버전을 남기세요. 처음 시작하는 AI는 원본 버전에서 진행하고, 인수인계받는 AI는 HANDOFF.md에 적힌 종료 버전에서 이어가세요. A는 입력 검증을 끝낸 뒤 멈추고 이미지 트랜잭션을 B에게 남깁니다. B는 먼저 전달받은 HANDOFF.md의 SHA-256을 기록하고 새 폴더에서 기존 검사를 재현한 뒤 나머지를 완성하세요. 대화 전문이나 다른 AI의 기억에 의존하지 마세요. 최종 결과 보고서에서 실제로 확인하지 않은 세션, 사용량, 사람의 판단, 공개 상태를 성공으로 꾸미지 마세요.
