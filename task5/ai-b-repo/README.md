# 짤·카드 스튜디오

이미지와 한글 문구를 조합해 밈·카드·SNS 게시용 이미지를 만들고 PNG/JPEG로 내려받는 제작 도구입니다. 서버, 빌드 도구, 계정 없이 `index.html` 하나로 동작합니다.

## 실행 방법

별도 설치나 빌드 과정이 없습니다. 저장소를 내려받아 `index.html`을 브라우저로 열면 바로 실행됩니다.

```bash
git clone <이 저장소 URL>
cd meme-card-studio
open index.html   # macOS
# 또는 브라우저에서 index.html을 직접 드래그해 열기
```

정적 호스팅(GitHub Pages, Netlify, Vercel 등)에 `index.html`을 그대로 올리면 별도 서버 설정 없이 공개 URL로도 사용할 수 있습니다. 로그인이나 계정 생성 없이 접근 가능한 정적 페이지입니다.

## 기능

- **이미지 불러오기**: PNG, JPEG 파일을 드래그하거나 버튼으로 불러옵니다. 확장자가 아니라 파일의 실제 바이트 시그니처를 검사해 위장된 파일(GIF/PDF/SVG/WEBP/EXE를 PNG로 위장한 경우 등)과 손상된 파일을 거부하고, 거부 사유를 화면에 표시합니다. 잘못된 파일을 넣어도 기존 작업(이미지·문구)은 그대로 유지됩니다.
- **문구 편집**: 문구 내용, 가로/세로 위치, 크기, 색상을 슬라이더·컬러 피커로 조정하며 캔버스 미리보기에 즉시 반영됩니다. 캔버스를 직접 드래그해 문구 위치를 옮길 수도 있습니다. 문구는 여러 개 추가·삭제할 수 있습니다.
- **화면비**: 1:1(정사각형), 4:5(세로형), 16:9(가로형) 세 가지를 지원하며, 미리보기 캔버스와 실제로 저장되는 파일의 해상도가 동일합니다.
- **내려받기**: 완성된 이미지를 PNG 또는 JPEG로 저장합니다.
- **JSON 내보내기/복원**: 현재 작업(이미지·문구·비율)을 JSON 파일로 내보내고, 그 파일을 다시 불러와 그대로 복원할 수 있습니다.
- **템플릿**: 자주 쓰는 구성을 이름 붙여 저장하고, 목록에서 불러오기·이름 수정·삭제를 할 수 있습니다. 브라우저의 로컬 저장소(localStorage)에 보관되며, JSON 내보내기로 다른 기기에 옮길 수 있습니다.

## 개인정보/보안

이미지와 문구는 브라우저 안에서만 처리됩니다. 서버로 업로드되거나 전송되지 않습니다.

## 기술 스택

순수 HTML/CSS/JavaScript (Canvas API)로 작성되었으며 외부 런타임 의존성이 없습니다. Google Fonts(Noto Sans KR, Black Han Sans, IBM Plex Mono)만 CDN에서 불러옵니다.
