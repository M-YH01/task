## 짧은 확인 방법 4줄
위치: 공개 비교 보고서의 소스 다운로드 → HANDOFF.md.
행동: 소스 압축 해제 → 해당 폴더에서 `node tools/receive.cjs ../ai-b-work` → `node ../ai-b-work/tests/run.cjs`.
통과 모습: 수신 해시 일치, A 시점 T01–T08 통과·T09–T10 실패(8/10); B 완료 기준은 10/10.
안 될 때 모습: 해시 불일치 오류 또는 8/10과 다른 재현 결과; 원본 소스를 다시 받아 Node.js 24로 확인.

## AI와 나의 판단 3줄 — 현재 대화에서 확인된 사실
AI에게 맡긴 일: 사용자가 AI A 역할 수행과 과제 3·4 소스 검토를 요청했다. AI가 개선 선정·검사 고정·입력 검증·인수인계를 수행했다.
직접 판단한 일: 사용자가 두 소스 폴더를 제공하고 AI A 역할을 지정했다. 개선의 최종 승인·검수 판단은 아직 기록되지 않았다.
AI 제안을 따르지 않은 일: 현재 대화에서 확인되지 않았다. 사용자가 수락·거절 이유를 밝히지 않아 이유를 대신 작성하지 않았다.

## 비교의 범위
동일 검사로 순차 인수인계를 검증하는 실험이다. B는 A 수정본에서 시작하므로 독립 모델 성능 비교나 공정한 속도 순위가 아니다. 특정 모델 API를 연결하지 않고 파일·버전·명령·해시를 통해 서로 다른 LLM에 동일 작업을 넘긴다.
