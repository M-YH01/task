# 사전 고정 실험 규약

## 작은 개선
과제 3 짤·카드 스튜디오의 JSON 복원을 검증하고, 복원 실패 시 기존 작업을 보존한다. 내보내기가 만드는 version 1 구조만 받는다. 원본: `C:/work/task/task3/index.html`. 제출 저장소의 초기 커밋과 SHA-256을 시작 소스로 기록한다.

## 동일 조건
- AI A와 B 각각 작업 시간 최대 60분, 도구 호출 최대 80회. 먼저 도달하는 상한에서 중단한다.
- 측정 시작: 검사/요청을 고정한 뒤 각 AI가 START 기록을 남긴 때. 측정 종료: END 기록 작성 직전. 준비 단계는 제외하고 구현·검사·인수인계·보고서·배포 준비는 포함한다.
- 호출: 실행 도구 안에서 호출한 실제 도구마다 1회, 직접 도구 호출도 1회. 단순 JavaScript 계산은 제외. 사용자에게 받는 최초 요청은 각 1회. 토큰/과금 사용량은 노출되지 않아 추정하지 않는다.
- A의 계획 중단 지점: T01–T08 구현/검사 후 코드 동결. T09–T10의 이미지 트랜잭션은 B에게 남긴다. 결함을 새로 만들거나 이미 통과한 검사를 일부러 깨뜨리지 않는다.
- B는 같은 최초 요청과 검사, 같은 원본 버전 정보를 받고 A 종료 버전에서 이어서 작업한다. 이전 대화 전문은 전달하지 않는다.
- B의 10/10 통과, 실제 수신 문서 해시, 무대화 재개 여부는 실제 B 세션이 기록한다. A가 대신 성공으로 기록하지 않는다.

## 검사 10개 (변경 금지)
공통 정상 입력은 `tests/cases.json`의 valid. 오류 시 aspectId/layers/activeLayerId/image가 모두 유지되고 오류 표시가 있으며 성공 표시는 없어야 한다. 검사 실행은 Node.js 24의 `node tests/run.cjs`.

| ID | 입력 | 기대값 |
|---|---|---|
| T01 | 정상 version 1, 4:5, 한글 문구, image:null | 비율·문구 복원, 이미지 제거, 성공 1회 |
| T02 | null | 기존 상태 유지, 오류, 성공 없음 |
| T03 | 정상 입력의 version:2 | 기존 상태 유지, 오류, 성공 없음 |
| T04 | 정상 입력의 aspectId:"2:3" | 기존 상태 유지, 오류, 성공 없음 |
| T05 | 정상 입력의 layers:[] | 기존 상태 유지, 오류, 성공 없음 |
| T06 | 첫 문구의 x:101 | 기존 상태 유지, 오류, 성공 없음 |
| T07 | 첫 문구의 color:"red" | 기존 상태 유지, 오류, 성공 없음 |
| T08 | image:"https://example.com/image.png" | 기존 상태 유지, 오류, 이미지 요청 0회 |
| T09 | 형식은 PNG data URL이나 디코딩 실패 이벤트 발생 | 기존 상태 전체 유지, 오류, 성공 없음 |
| T10 | 유효 PNG data URL, 지연 후 load 이벤트 발생 | 로딩 중 기존 상태/성공 없음; load 후 전체 복원/성공 1회 |

검사는 실제 HTML의 복원 함수 구간을 Node VM에서 실행한다. DOM 렌더 함수와 이미지 디코더만 대체하며 네트워크·패키지 설치 없이 결정적으로 실행한다. 실제 브라우저의 파일 선택·캔버스·디코딩 검증을 대체하지 않으므로 B는 최종 브라우저 확인을 별도로 수행한다.
